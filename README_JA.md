# Sub2API

> 日本語 README は、このブランチの独立リリース方針に合わせて書き直し中です。古い upstream のインストール URL、デモ、スポンサー情報を案内しないよう、当面は [README.md](README.md) を参照してください。

このリポジトリは独立してメンテナンスされる Sub2API ブランチです。

- 独立したリリースラインは `v1.0.0` から開始します。
- upstream `Wei-Shaw/sub2api` の `main` ブランチを自動追従しません。
- upstream PR は個別にレビューし、このブランチの設計方針に合う場合のみ取り込みます。
- バイナリ、systemd サービス、イメージ basename は互換性のため `sub2api` のまま維持します。

インストール、アップグレード、リリース方針は [README.md](README.md) を参照してください。
